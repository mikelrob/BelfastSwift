# Belfast Swift

The website for **Belfast Swift** — Belfast's iOS & Swift developer meetup community.

🌐 **Live site:** [belfastswift.com](https://belfastswift.com) · [belfastswift.co.uk](https://belfastswift.co.uk) · [belfastswift.ie](https://belfastswift.ie)

## Stack

Plain HTML, CSS, and JavaScript. No build tools or dependencies.

- **Fonts:** Inter via Google Fonts
- **Analytics:** [Umami](https://umami.is)
- **Themes:** Two CSS themes defined in `style.css` — `swift` (dark, orange accent) and `belfast` (dark green, gold accent). Active theme is set via `data-theme` on `<html>`.

## Deployment

Hosted on GitHub Pages. Push to `master` to deploy.
